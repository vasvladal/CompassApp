🧭 CompassApp

True Heading · GPS Location · OpenStreetMap · Made with Kotlin Multiplatform

CompassApp is a cross-platform compass and navigation tool built with Kotlin Multiplatform and Compose Multiplatform. It runs on Android and iOS from a single codebase, showing your true heading (corrected for magnetic declination), current GPS coordinates, and an interactive map using free OpenStreetMap tiles.

✨ Features

🧭True Heading
Displays your direction in degrees and cardinal points (N, NE, E, …). Automatically corrected for magnetic declination using your GPS position.
📍GPS Location
Shows your current latitude/longitude in both decimal and DMS formats. Includes altitude, accuracy, and speed when available.
🗺️Interactive Map
OpenStreetMap view with a marker at your location. Zoom and pan to explore your surroundings — no API key required.
📐Level & Tilt
Visual bubble level shows your device's pitch and roll, helping you keep the phone flat for accurate readings.
🔄Compass Calibration
On-screen calibration guide: rotate your device in a figure-8 motion to improve heading accuracy.
📊Magnetic Strength
Displays the local magnetic field strength in microteslas (μT). Useful for detecting interference.

🧭 How It Works

Heading & Magnetic Declination

The device's magnetometer provides a magnetic heading (relative to magnetic north). To show true heading (relative to geographic north), the app applies a correction called magnetic declination.

  • Android uses the GeomagneticField API to calculate declination from your GPS coordinates.
  • iOS uses CLHeading.trueHeading directly when location services are active.

The formula used:

// True Heading = Magnetic Heading + Declination
val trueDegrees = (magneticDegrees + declination + 360f) % 360f

Location Tracking

The app uses the dev.jordond.compass library for geolocation, which provides:

  • Continuous location updates via locationUpdates flow
  • Reverse geocoding to show your place name (city/locality)
  • Altitude, accuracy, and speed information

Map Rendering

Maps are rendered using Leaflet inside a WebView, with multiple fallback tile providers:

  • OpenStreetMap (primary)
  • OpenTopoMap (topographic, fallback)
  • HOT (Humanitarian OpenStreetMap, fallback)

This approach works without any API keys and automatically retries if a provider fails.

🛠️ Technology Stack

Kotlin Multiplatform Compose Multiplatform Kotlin Coroutines Leaflet.js OpenStreetMap AndroidX Startup CLLocationManager (iOS) SensorManager (Android)

The app is structured as a Kotlin Multiplatform project with three main modules:

  • shared — Common business logic (compass, location, UI composables).
  • app — Android application wrapper.
  • iosApp — iOS application wrapper (SwiftUI + ComposeUIViewController).

📱 Usage Tips

  • Get a fix: Wait for GPS to lock (the place name will appear). The compass works best with a GPS fix for declination correction.
  • Hold flat: Keep your device horizontal for best results. The bubble level helps you stay level.
  • Calibrate: If the heading seems off, tap "Calibrate Compass" and move the device in a figure-8 pattern.
  • View map: Tap "Show Map" in the location details panel to see your position on OpenStreetMap.
  • Permissions: The app requires location permissions (GPS) and internet access (for maps).

🔐 Permissions

The app requests the following permissions:

📍 ACCESS_FINE_LOCATION 📍 ACCESS_COARSE_LOCATION 🌐 INTERNET 📶 ACCESS_NETWORK_STATE

On iOS, the equivalent NSLocationWhenInUseUsageDescription is used. All permissions are required for the core compass and map functionality.
