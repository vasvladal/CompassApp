🧭 CompassApp

Истинный азимут · GPS-координаты · OpenStreetMap · Сделано на Kotlin Multiplatform

CompassApp — это кроссплатформенный компас и навигационный инструмент, созданный на Kotlin Multiplatform и Compose Multiplatform. Приложение работает на Android и iOS из единой кодовой базы, показывая истинный азимут (с поправкой на магнитное склонение), текущие GPS-координаты и интерактивную карту на основе бесплатных тайлов OpenStreetMap.

✨ Возможности

🧭Истинный азимут
Показывает направление в градусах и сторонах света (С, СВ, В, …). Автоматически корректируется с учётом магнитного склонения по вашим GPS-координатам.
📍GPS-местоположение
Показывает текущие широту и долготу в десятичном формате и в градусах, минутах, секундах. Доступны высота, точность и скорость.
🗺️Интерактивная карта
Карта OpenStreetMap с маркером вашего местоположения. Масштабируйте и перемещайтесь — без API-ключей.
📐Уровень и наклон
Визуальный пузырьковый уровень отображает наклон и крен устройства, помогая держать телефон горизонтально для точных показаний.
🔄Калибровка компаса
Экранная инструкция по калибровке: вращайте устройство восьмёркой, чтобы повысить точность показаний.
📊Напряжённость поля
Отображает напряжённость магнитного поля в микротеслах (мкТл). Полезно для обнаружения помех.

🧭 Как это работает

Азимут и магнитное склонение

Магнитометр устройства выдаёт магнитный азимут (относительно магнитного севера). Чтобы показать истинный азимут (относительно географического севера), приложение применяет поправку — магнитное склонение.

  • Android использует API GeomagneticField для расчёта склонения по координатам GPS.
  • iOS использует CLHeading.trueHeading напрямую, когда службы геолокации активны.

Формула расчёта:

// Истинный азимут = Магнитный азимут + Склонение
val trueDegrees = (magneticDegrees + declination + 360f) % 360f

Отслеживание местоположения

Для геолокации используется библиотека dev.jordond.compass, которая предоставляет:

  • Непрерывные обновления местоположения через поток locationUpdates
  • Обратное геокодирование для отображения названия места (город/населённый пункт)
  • Информацию о высоте, точности и скорости

Отрисовка карты

Карты отображаются с помощью Leaflet внутри WebView с несколькими резервными провайдерами тайлов:

  • OpenStreetMap (основной)
  • OpenTopoMap (топографический, резервный)
  • HOT (Humanitarian OpenStreetMap, резервный)

Такой подход не требует API-ключей и автоматически переключается при сбое провайдера.

🛠️ Технологический стек

Kotlin Multiplatform Compose Multiplatform Kotlin Coroutines Leaflet.js OpenStreetMap AndroidX Startup CLLocationManager (iOS) SensorManager (Android)

Приложение построено как проект Kotlin Multiplatform с тремя основными модулями:

  • shared — общая бизнес-логика (компас, геолокация, UI-компоненты).
  • app — обёртка для Android-приложения.
  • iosApp — обёртка для iOS-приложения (SwiftUI + ComposeUIViewController).

📱 Советы по использованию

  • Дождитесь GPS-фиксации: Подождите, пока появится название места. Компас работает точнее при наличии GPS для корректировки склонения.
  • Держите горизонтально: Для наилучших результатов держите устройство ровно. Пузырьковый уровень помогает контролировать положение.
  • Калибровка: Если азимут кажется неточным, нажмите "Калибровка компаса" и совершите восьмёрку устройством.
  • Карта: Нажмите "Показать карту" в панели сведений о местоположении, чтобы увидеть своё положение на OpenStreetMap.
  • Разрешения: Приложению требуются разрешения на геолокацию (GPS) и доступ в интернет (для карт).

🔐 Разрешения

Приложение запрашивает следующие разрешения:

📍 ACCESS_FINE_LOCATION 📍 ACCESS_COARSE_LOCATION 🌐 INTERNET 📶 ACCESS_NETWORK_STATE

На iOS используется аналогичное разрешение NSLocationWhenInUseUsageDescription. Все разрешения необходимы для работы компаса и карты.
