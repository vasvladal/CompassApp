🧭 CompassApp

Architecture Documentation · Kotlin Multiplatform · Compose Multiplatform

CompassApp is a cross-platform compass and navigation tool built with Kotlin Multiplatform and Compose Multiplatform. It runs on Android and iOS from a single codebase, showing true heading (corrected for magnetic declination), GPS coordinates, and interactive maps using free OpenStreetMap tiles.

✨ Features

🧭True Heading
Displays direction in degrees and cardinal points. Automatically corrected for magnetic declination.
📍GPS Location
Shows latitude/longitude in decimal and DMS formats. Includes altitude, accuracy, and speed.
🗺️Interactive Map
OpenStreetMap view with marker at your location — no API key required.
📐Level & Tilt
Visual bubble level shows device pitch and roll for accurate readings.
🔄Compass Calibration
On-screen guide: rotate device in a figure-8 motion to improve accuracy.
📊Magnetic Strength
Displays local magnetic field strength in microteslas (μT).

🔐 Permissions

The app requests the following permissions:

📍 ACCESS_FINE_LOCATION 📍 ACCESS_COARSE_LOCATION 🌐 INTERNET 📶 ACCESS_NETWORK_STATE

On iOS, NSLocationWhenInUseUsageDescription is used. All permissions are required for core functionality.

📱 Usage Tips

  • Wait for GPS fix: The compass works best with GPS lock for declination correction.
  • Hold flat: Keep your device horizontal for best results. Use the bubble level.
  • Calibrate: If heading seems off, tap "Calibrate Compass" and move in a figure-8 pattern.
  • View map: Tap "Show Map" to see your position on OpenStreetMap.
